### What I practiced

I practiced basic Linux file navigation by first checking my current working directory with pwd. I then navigated to /var/log using an absolute path, returned to my home directory using ~, and used cd - to return to /var/log. Finally, I used ls -lh to view the contents of /var/log in long format with human readable file sizes.

### What surprised me

What surprised me was how cd - works like a shortcut between two locations it allowed me to quickly return to /var/log after moving back to my home directory.
