## less displays the content of a file too,except that less displays page by page.##
## head shows the first 10 lines by default content of a file. ##
## head -n this allows you to choose how many lines you want to view. ##
## tail shows the last 10 lines by default content of a file. ##
## tail -f the f stands for follow, this command streams files new lines in real time. ##
## wc stands for word count, it counts no. of lines,words and bytes.## 
## wc -l this command count number of line without word and bytes.##
## file this command shows the type of a file by checking its content.##
## stat this command shows the size, permissions and timestamps of a file.##
