#In (hard link) Creates a hard link, which is another directory entry that points to the same underlying file data.

#realpath Shows the absolute path of a file or directory, resolving symbolic links and relative paths.
#basename Extracts the final part of a path, usually the filename.
#dirname Extracts the directory part of a file path, removing the filename.
#pushd/popd saves your current directory and moves to another directory, while popd returns you to the previously saved directory.
