# linux-command-mastery-challenge
A 30 Day Linux Command Challenge designed to build practical Linux skills through 300 commands.
This 30 day Linux command mastery challenge is a hands on learning journey designed to build practical command line fluency through 300 Linux commands and their derivatives over 30 consecutive days. The challenge covers six themed phases, including navigation, file management, permissions, users and groups, package management, environment configuration, text editing, processes, services, networking, scripting, and SSH. Each day includes a practice drill, a Command Journal entry, a GitHub commit, and a LinkedIn article, providing consistent evidence of hands on learning and progress. By the end of the challenge, the public GitHub repository and 30 article LinkedIn history demonstrate not only knowledge of Linux commands, but the ability to apply them consistently in real command line environments.
