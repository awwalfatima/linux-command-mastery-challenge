## find -name this command is use for searching files, i.e find . -name "nameofthefile.extension", the . is when you are looking that directory, file path can be put in place of .(dot).
## find -type the -type allows you to specify the type of file you want to search
## find -size this command is useful as a way to find spacehogs on your system
## find -mtime finds directories that where modified at a particular time, i.e find /var/log -mtime -7 (this will find files in var/log that were modified in less than 7 days)
## find -perm this command filters files by their permission.
## locate search files by name
## updatedb rebuilds locate database by rescanning file system
## du stands for disk usage, it shows how much disk space files and directories are using,it is used when you want to check which folder or file is taking up space
## du -sh in this command, the s stands for summarize, and the h stands for human readable, so du -sh gives a summarized human readable disk space  
## df -h returns human readable disk free which shows how much space is used on mounted filesystems in human readable format than numbers.
