#vim <file> to open a file you want to edit, syntax: vim name of the file. vim notes.txt
#i (insert mode) insert mode allows you to type. 
#Esc (command mode) command mode brings you back to normal mode,whereby you cant type in this mode
#:w w stands for write, :w saves your file to disk  
#:q stands for quitting, when you want to exit vim 
#:wq / :x this command allows you to save and exit the vim
#:q! this allows you to quit without saving, its a force quit, its forcefully quits you from vim. 
#dd deletes an entire line, the line where you cursor is, you can add a number at the begininig for multiple number of lines,i.e 2dd this will delete 2 lines
#yy /p for copy and pasting, yy is for copy, and p for paste.
#u /Ctrl+r u stands for undo, to undo your recent commands, ctrl+r redos changes
